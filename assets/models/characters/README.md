# Hero character models

There are TWO KINDS OF HERO in this folder, and the `.tscn` is what says which:

* **Skinned** — one `.glb` holding one mesh on a 23-bone MakeHuman rig
  (`<hero>_parts/<hero>_skinned.glb`), built by `scripts/build_hero.py` from a
  `HEROES` row. `hero_rig.gd` finds the `Skeleton3D` **by type** and poses it with
  `hero_rig_skeleton.gd`. Teibi (bead godot-test1-5u3.3) and Windman (bead 5u3.5)
  are here.
* **Separate parts** — a folder of GLB parts assembled by a `.tscn` whose
  `Body/LeftArm` / `RightArm` / `LeftLeg` / `RightLeg` containers are rotated at run
  time, the limbs found **by exact node name** and posed by `hero_rig_limbs.gd`.
  Primm (until bead 5u3.6) and Phoboman (for good — his sphere body stays
  generated by owner ruling) are here.

Either way there is no `AnimationPlayer`: the pose is a pure function of (hero,
phase, gait state) in both drivers. See CLAUDE.md, "Player and camera".

The predators in this directory are single `.glb` files instead; their contract is
`scripts/predator_parts.py`.

## Windman

- Body: `windman_parts/windman_skinned.glb` — **authored and skinned**, one mesh,
  23 bones, vertex colours, no texture. Built by
  `scripts/build_hero.py --hero windman` (Blender + MPFB2, by hand — the CI runner
  has neither); `PROVENANCE.md` carries the row and `scripts/hero_manifest.json`
  is the staleness gate CI can run. His head is part of this mesh: the separate
  `windman_head_authored.glb` retired with bead 5u3.5, the face recipe of record
  being `scripts/spike_z3e_head.py`'s `HEROES["windman"]` row, which
  `build_hero.py` imports.
- The chest **"W"** is vertex colour, painted by `build_hero.paint_chest_glyph`
  over a chest split once by `densify_chest`. It is not geometry and not a texture.
- Prop: `windman_parts/windman_fan.glb` — the ONLY thing
  `scripts/generate_windman_separate.py` still writes, and the reason `windman` is
  still a name in `build.yml`'s hero loop. `windman_updated.tscn` hangs it on the
  `hand_r` bone with a `BoneAttachment3D`.
- Scene: `scenes/characters/windman_updated.tscn` — this is the scene
  `player_controller.gd`'s `CHARACTERS` array loads.

### Rebuilding

```bash
python3 scripts/generate_windman_separate.py          # the fan; CI runs this and diffs it
perl -e 'alarm 1500; exec @ARGV' blender --background --python-exit-code 1 \
    --python scripts/build_hero.py -- --hero windman  # the body; by hand, not in CI
godot --headless --path . --import                    # after either
```

The pinned toolchain is `scripts/requirements.txt`. CI rebuilds every generated
model and **fails on a dirty tree**, so a generator change and its regenerated
`.glb` go in the same commit; a rebuilt skinned body must carry its
`hero_manifest.json` row with it for the same reason.
