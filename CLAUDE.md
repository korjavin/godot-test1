# CLAUDE.md

**This file is a map, not the territory.** It says where things live and lists the
rules you would break without knowing. The reasoning, the measured numbers and the
history live **next to the code** — every script opens with a banner and every
`_selfcheck.gd` header says what it asserts. Read the file you are changing before
you change it. Do not grow this file with detail that belongs beside the code.

## Project

CrimeKickers: a Godot **4.5** 3rd-person endless-runner. Four switchable heroes walk an
infinite procedural field toward the authored city of Budapest, chased by predators and
by the GD-SURVEY corporation whose HQ (the tower) jails captured heroes. 2–4 players
share a world over WebRTC. The web export is the performance target.

## Commands

No test suite, linter or build script. Correctness is guarded by **headless
self-checks**, one per subsystem, each printing `SELFCHECK OK`:

```bash
godot --path . scenes/main.tscn                                  # run the game
godot --headless --path . --script res://scripts/<name>_selfcheck.gd   # one check
ls scripts/*_selfcheck.gd                                        # the suite (CI runs all)
godot --headless --path . --import                               # after editing assets/translations/ui.csv, before locale_selfcheck
mkdir -p build/web && godot --headless --export-release "Web" build/web/index.html && ./serve.sh
bash scripts/mp_e2e.sh                                           # two-instance MP e2e (needs go + godot)
python3 scripts/predator_parts.py                                # rebuild + verify every enemy .glb
cd server && go test ./...                                       # the Go lobby
```

Run the checks covering what you touched; the map below names them. A check passes only
if it exits 0, printed `SELFCHECK OK` **and** logged no `SCRIPT ERROR` — Godot exits 0
on a runtime error.

**Writing a self-check:** a runtime error aborts only the function it lands in, so a
check that dies halfway still prints OK. `scripts/selfcheck_sentinel.gd` is the guard:
`Sentinel.isolate_user_state()` first in `_initialize()`, `Sentinel.done("name")` as
the last statement of every check function, `Sentinel.finish(self)` at the report site.
`progression_selfcheck` audits every check for both.

**3D models are generated by Python** (`scripts/generate_*.py`, pinned toolchain in
`scripts/requirements.txt`). CI rebuilds them and fails on a dirty tree, so a generator
change and its regenerated `.glb` go in the same commit. `scripts/predator_parts.py` is
the shared toolkit and the contract every enemy mesh must honour; `export_faceted()`
there is the one export seam for every shipped `.glb` (heroes included) — read its
docstring before touching it. The live Windman is `windman_parts/` assembled by
`scenes/characters/windman_updated.tscn`; `windman.glb` is dead art.

`.gd.uid` files are Godot's; don't hand-edit them.

## Rules you would break without knowing

### Node discovery is group-based, not reference-based
Systems find each other with `get_first_node_in_group(...)` guarded by `has_method`, never
`$`-paths or exported references, so a scene run standalone degrades instead of erroring.
**`"player"` is the LOCAL player only** — a remote peer's avatar joins no group and adds
no physics body, so nothing can follow a hologram.

### The world is deterministic, and the RNG stream is the contract
- Every spawn site is a pure function of (chunk or station index, `run_seed`) via
  `hash(Vector3i(a, b, run_seed))`. Independent features use their **own salt and
  coordinate primes**, never a draw from the shared chunk stream.
- **Never add or remove an RNG draw** in an existing stream: one extra draw moves every
  spawn in the world. Dispatch (which species, which box kind, which boss) costs no draw.
  Where a feature removes a placement, `continue` **after** the draws that produced it.
- `set_run_seed()` is the only seed write and `_drop_seeded_memos()` clears every cache
  derived from it. A memo that outlives a re-seed hands a multiplayer joiner the wrong world.
- Ambience (weather, fauna, crowd, traffic, projectiles) is deliberately **outside** the
  contract on a `randomize()`d RNG. Don't wire it to the seed; in a room the master
  simulates and peers replay.

### Geometry goes through the chunk batch
- Everything decorative is `create_box()` → one MultiMesh per box **kind** and one
  `StaticBody3D` per chunk. Never a `MeshInstance3D` or a body per object. Anything
  spawned per chunk parents to the chunk or it leaks.
- Every unit mesh is inscribed in the unit cube, so `dimensions` is always the bounding
  box; collision follows the kind (`ChunkBatch.collision_shape_for`). A new box-kind
  consumer is judged by eye by the owner and billed in `batch_selfcheck` check 5.
- **Footprints are the shared currency**: `{pos, radius, top, climbable}` appended to
  `obstacles`; later spawners read it. Settle reward coins before appending the feature's own.
- **Scarcity is one rule for every biome**: content thins with distance through
  `scarcity_at()` in exactly three forms (see `_scarcity_keep`); predators, bosses and road
  coins are never thinned; the mountain massif is the single exemption.

### Two authored exceptions, and only two
- **The tower** is one building at one constant site, built from `tower_shell.gd`'s box
  table, parented to the terrain manager so unloading can never free it. Its interior
  is `tower_plans.gd` ASCII storeys: **a new storey is a `STOREYS` row plus `TOWER_GRAPH`
  rows and no builder code**; nothing in the plan is seeded or hashed. No interior
  traversal may need a jump — vertical movement is ramps and gates. `tower_selfcheck` is
  the softlock audit (graph walk + grid flood fill); keep gate/room ids stable, they are
  persisted.
- **Budapest** is authored too (`budapest_plan.gd`: no `run_seed`, no `randf`, no
  `hash(`) but streamed through ordinary chunks — a landmark bigger than a chunk is
  **sliced** on the chunk grid, seeded by slot index, never manager-parented. City chunks
  cast no shadow (owner ruling). Every grid cell not reserved by the plan is a hollow
  ring of buildings; facades are bands, never a box per window; streets are clear by
  construction. Spawner policy inside the rect is per system (`in_budapest()`), not a
  blanket exclusion.

### The world is flat, and CPU and GPU must agree
Ground is y = 0 everywhere. Mountains are impassable box massifs, rivers are tinted
wading bands with a deep channel that pushes you out. `_biome_noise` in
`endless_terrain.gd` and `biome_noise` in `ground.gdshader` are **one function in two
languages — edit them together**, and keep the GDScript port's `Vector2` fp32 routing.
`FIELD_ALTITUDE` is a spike that ships `false` (`docs/field-altitude-spike.md`).

### Speeds are a lattice
`WALK_SPEED` < every species' `chase_speed` < `MAX_CHASE_SPEED` < the slowest run:
walking gets you caught, running always escapes. The `"burst"` arm is the one bounded
exception and is measured over its whole cycle. There is no walk-speed skill effect and
there may never be one. `SIM_RADIUS` in the LOD manager stays above every detection
radius and every boss territory.

### Predators are data
A species is a `SPECIES` row (`species_table.gd`), a `.tscn`, and one line in
`BIOME_SPECIES` / `BIOME_BOSS` — never a subclass. `species` and `setup_as_boss()` are
set **before `add_child`**. Behaviour is one `match` on the row's `behavior`, each arm one
`_behave_*()` call; steering math is pure in `croc_steering.gd`. Anything true of "boss"
lives once in the `is_boss` layer (territory leash, crush immunity — an ordering, not a
flag). Opt-outs (`stink_immune`, `crush_immune`, `captures_hero`, `fears_giant_radius`,
`view_cone_deg`, `scent_radius`) are row keys read with `spec.get`, never species-name
tests. `enemy_spawn_selfcheck` iterates the tables, so a new row is covered the day it
lands and a new behaviour string must bring a probe to `enemy_behavior_selfcheck`.

### Capture, lives and the ending
There are no hearts. A `captures_hero` grab jails the active hero (`captive_heroes`,
per-run, non-monotone, mirrored into the tower and room-wide over the `cap` verb); an
empty free set is the **only** game over and it fires immediately. Every other contact is
a coin tax and a soft respawn in place; the caption says which happened. Availability is
`hand ∩ free` at one site (`switch_to_next_character`); the auto-switch goes through
`set_active_character()`. Inside the HQ a death knocks you back to the last checkpoint,
gated on `TowerInterior.inside_walls()`, never on the group merely existing.

### Persistence is monotone
`best_run_store.gd`: cfg file, `localStorage`, lobby `GET/POST /best`. Every field merges
with max/union, so a late reply can never lower a record. Progression is
run-independent; coins are never deducted from lifetime totals. The captive set stays
out of it precisely because it is not monotone.

### The pause is refcounted
`PauseHub.take(who)` / `release(who)` is the only writer of `tree.paused`;
`pause_selfcheck` greps for any other. Only P travels to the room (as a presence bit);
every other overlay pauses locally. Panels open on raw keycodes outside the input map;
gameplay input goes through named actions.

### Multiplayer
- **`_rtc` is never assigned to `multiplayer.multiplayer_peer`** — it is a plain
  `PacketPeer`. `bytes_to_var`, never `_with_objects`.
- Everything relayed is untrusted: type-check in `mp_codec.gd`, drop malformed, rate-limit
  mutating verbs. A new verb is a parser in `mp_codec.gd` and a handler in `mp_manager.gd`.
- The lobby (`server/`) is signalling and membership only; it never inspects payloads.
  A new route also needs a Traefik path rule in `server/docker-compose.yml`.
- Seed and captive set ride the lobby relay as well as the mesh (they must reach peers
  whose ICE is unfinished). Crocodiles are master-simulated, never network-spawned.
- **Runtime state that gates gameplay is shared on the herd's shape (`mp_world_sync.gd`) — the master simulates,
  peers replay — never by seeding.** Storms (`wx`, one packet per croc-sync tick, `weather_manager.gd`
  owns both ends and the silence timeout), ranged-boss shots (`shot`, reliable, one per shot,
  replayed with the body's own row params, lethality local) and the HQ's opened gates (`gate`,
  anyone-to-everyone, plus `g` on the `room` packet and `go` in the join snapshot from the master;
  a non-master's own set drains once per join under half the verb budget). Clear clouds, birds,
  crowd and traffic stay per-peer cosmetic. Storms are rolled around every room member
  (owner ruling A, bead `gyd`). Each verb's ceilings (older builds, RTT lag) are written
  at its send site. Beads `vej`, `coq`, `d81`, `gyd`.
- Voice/video is web-only, on browser `RTCPeerConnection`s, one const JS string in
  `scripts/voice_js.gd` (aliased as `VOICE_JS` from `voice_chat.gd`); its `mp_manager` seam is three functions. **No JS snippet may return
  a bare boolean through `JavaScriptBridge`** — return 1/0 (checked by `intro_selfcheck`).
  The camera is cartooned before encoding and the raw device track never leaves the sender.
  The face detector is fetched at build time by `scripts/fetch_vendor.sh` against
  `web/vendor/mediapipe/vendor.lock`, never committed, never a CDN.

### Player and camera
No `AnimationPlayer`: limbs are found **by exact name** (`Body`, `LeftArm`, `RightArm`,
`LeftLeg`, `RightLeg`, optional `Head`) and driven by sine waves in `player_animation.gd`.
`CameraArm` is a `SpringArm3D` and overwrites its children's position — use
`h_offset`/`v_offset` or move the arm. Transient ability state is cleared on respawn,
character switch and leaving the HQ. Abilities live in `player_abilities.gd`, dispatched
by name with per-character cooldowns; two change inside the HQ via the shell's `sheltered()`.

### HUD, audio, locale
- `hud_theme.gd` is the one style source: the six palette hexes are typed there and
  nowhere else (`hero_hud_selfcheck` greps). Panels adopt `HudTheme.theme()` on their own
  root — never project-wide. `draw_*` HUDs read the consts.
- All audio is synthesized in `sound_manager.gd`; no asset files. Every play path waits
  for `unlock_audio()`. Acquisition cues fire on the `is_chasing` edge in
  `_announce_acquisition()`, which is reached from both the local and remote state paths.
- Translation key = the English string; `tr()` explicitly on format strings. German fit is
  measured by `locale_selfcheck`, on every face a string can be drawn in.

### Performance
- Entity counts are never reduced as an optimization; distant crocodiles are slept, never
  removed. Invisible optimizations are global, visual ones are web-gated.
- `\fo` is the measurement tool and it logs every frame spike; a perf bead touching the
  city, crowd, traffic or tower carries a web reading taken on a **debug** export
  (`\fb`/`\fh` are dead in release).
- The ambient knob is `ambient_light_sky_contribution`, not `ambient_light_energy`
  (a no-op at sky contribution 1.0); `light_angular_distance` is Forward+ only.

### CI/CD
`build.yml` shards every `scripts/*_selfcheck.gd` by measured cost
(`selfcheck_shards.sh`, never a list of names in YAML) and runs the model rebuild gate.
Merging to `master` deploys: `deploy-stack` is the **single writer of the `deploy`
branch**, pins images by SHA (never `:latest`), prunes the host's unused images before
the webhook, and fails the job if Portainer's stack hash does not reach the pinned
commit. The lobby's `/healthz` reports signalling only and must never consult the
best-scores store. Both are written up in the workflow and `server/health_test.go`.

## Conventions
- GDScript with explicit type hints; tunables as consts at the top of the script.
- Static "family" libraries (`terrain_*`, `tower_*`, `city_*`, `mp_*`) reach a sibling
  family **through the node that owns the state**, never directly; a family's own
  self-check reads its subject directly, not through a forwarder. A `const` alias or a
  type annotation is a parse-time reference — one direction only, or it is a cycle.
- Arcade gravity, coyote time, buffered jumps, `move_toward` for horizontal velocity.
- Match the surrounding comment density. This codebase is written to be read.
